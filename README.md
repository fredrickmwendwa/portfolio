# Fredrick Mwendwa — Portfolio V2

React (JavaScript) + Vite.

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # outputs /dist
    npm run preview   # serve the production build

## Edit content
- Projects, journey, stack, principles: `src/data.js`
- Project screenshots: put files in `public/images/projects/` and set `image` in `src/data.js`
- Styles / design tokens: `src/styles.css` (`:root` at the top)
- Before deploying, replace `YOUR-DOMAIN.vercel.app` in `index.html`, `public/robots.txt`, `public/sitemap.xml`
