About

Backend Software Engineer from Nairobi, Kenya

I'm Fredrick Mwendwa, a Computer Science graduate from Kiambu National Polytechnic. I'm based in Nairobi, Kenya, and I spend most of my time on the backend: building APIs, designing databases, and figuring out how the pieces of a web application should actually talk to each other.

Python and Django are the core of how I build things. I pair them with Django REST Framework when an application needs to serve an API, and PostgreSQL for the database layer. I also work with SQL more broadly, and I've spent time with PHP and Laravel, and with Microsoft SQL Server on the database side. On the frontend I'm comfortable with JavaScript, HTML, and CSS, enough to build and understand the interfaces my APIs are feeding, even if that's not where I want to spend most of my time.

I like backend work because it rewards being precise: a schema either models the problem correctly or it doesn't, an endpoint either handles the edge case or it breaks something down the line. I'm still early in my career and I'm looking for an internship or a junior software engineering role where I can contribute, keep learning from people who've done this longer than I have, and grow into a stronger engineer.
